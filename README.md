# Tamagochi Tasker

Web app de tarefas com Tamagochi virtual — humor, evolução, histórico diário e sons retro.

## Como usar localmente

Abra o arquivo `index.html` no navegador (duplo clique).

## GitHub Pages

O site é publicado automaticamente pelo GitHub Actions ao fazer push na branch `main`.

URL: `https://anaraissans.github.io/tamagochi-tasker/`

## Estrutura

```
index.html      → página principal
style.css       → visual retro / LCD
js/             → lógica modular (TamagochiApp)
sounds/         → efeitos sonoros (.ogg)
```

## Dados

As informações ficam no `localStorage` do navegador (tarefas, personagem, histórico).
